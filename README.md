# To-Do List

A simple Python-based To-Do List application that allows users to manage their daily tasks.

## Features

- Add tasks
- View tasks
- Update tasks
- Complete tasks
- Delete tasks
- Simple command-line interface
- Handles invalid user input

## Technologies Used

- Python
- Object-Oriented Programming

## How It Works

1. The user starts the application.
2. The program displays a menu.
3. The user selects an option.
4. The user can add, view, update, complete, or delete tasks.
5. The task list is updated based on the user's choice.
6. The program continues until the user chooses to exit.
